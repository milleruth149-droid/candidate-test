# מערכת ניהול בקשות (Requests Management System)

פרויקט זה הוא מערכת מקיפה לניהול, סינון וחיפוש בקשות, הבנויה בארכיטקטורה נקייה (Clean Architecture) עם שרת ASP.NET Core וממשק Angular מתקדם.

---
